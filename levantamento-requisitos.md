# Levantamento de Requisitos — Salesforce CRM

## 1. Objetivo

Este documento faz parte de um estudo de caso fictício e tem como objetivo identificar as necessidades de uma empresa que deseja organizar melhor seus clientes e suas oportunidades comerciais.

## 2. Cenário atual

A empresa fictícia utiliza planilhas para registrar clientes e acompanhar negociações. Com o crescimento das atividades, tornou-se mais difícil localizar informações, lembrar de retornos e acompanhar o andamento das vendas.

## 3. Perguntas para entender o negócio

Antes de sugerir uma solução, um consultor precisa entender como a empresa trabalha atualmente.

- Como os dados dos clientes são registrados hoje?
- Quem pode consultar e atualizar essas informações?
- Como a equipe acompanha os contatos e os retornos aos clientes?
- Quais são as etapas de uma negociação comercial?
- Como os vendedores registram as oportunidades de venda?
- Quais relatórios e indicadores a gestão precisa acompanhar?
- Quais são as principais dificuldades da equipe no processo atual?

## 4. Requisitos iniciais

Com base no cenário fictício, foram identificadas estas necessidades iniciais:

| Código | Requisito | Objetivo |
|---|---|---|
| RF01 | Cadastro de clientes e contatos | Centralizar as informações comerciais |
| RF02 | Registro de atividades | Acompanhar contatos e retornos |
| RF03 | Controle de oportunidades | Visualizar as etapas das negociações |
| RF04 | Relatórios comerciais | Acompanhar os resultados das vendas |

Esses requisitos são preliminares e precisariam ser validados com os responsáveis pela empresa antes de qualquer implantação.

## 5. Possível utilização do Salesforce

O Salesforce CRM poderá ser avaliado como uma alternativa para atender às necessidades identificadas, considerando os recursos disponíveis, as regras do negócio e as permissões de acesso necessárias.

A escolha e a configuração dos recursos dependeriam das respostas obtidas durante o levantamento.

## 6. Próximas etapas

1. Validar as necessidades com os responsáveis pelo processo comercial.
2. Priorizar os requisitos mais importantes.
3. Avaliar quais recursos do Salesforce atendem a cada necessidade.
4. Definir os indicadores que serão utilizados para acompanhar os resultados.

## Observação

Este documento é um exercício de aprendizagem baseado em um cenário fictício. Os requisitos e as propostas ainda não foram validados com um cliente real e não representam uma implantação realizada.
